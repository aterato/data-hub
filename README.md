# data-hub

[ページはこちら](https://aterato.github.io/data-hub/)

PC とモバイルデバイスのあいだで開発データをやり取りし、連携の動作を確かめるためのテスト用リポジトリです。

デバイスや利用環境が異なる場合でも、データをどのように共有・更新できるかを試し、開発中の機能やワークフローを検証する場として利用します。小さな実験から実際の利用を想定した確認まで、試した内容や気づきを整理しながら、デバイス間連携の改善につなげていきます。

## 目的

- PC とモバイルデバイス間の開発データ連携をテストする
- データの共有、更新、受け渡しなどの動作を確認する
- デバイスや環境による違い、連携時の課題を把握する
- テスト結果や手順を記録し、今後の開発に活用する

## このリポジトリの位置づけ

このリポジトリは、開発・検証を目的とした実験のための場所です。ここに置かれるファイルや手順は、連携テストの過程で変更されることがあります。重要なデータや唯一の保管先としてではなく、検証用データを使ったテストに利用してください。

## 利用時の注意

- 個人情報、認証情報、その他の機密情報は登録しないでください。
- テストに使うデータは、必要に応じてサンプルデータや複製を用意してください。
- データの更新・削除が各デバイスにどう反映されるかを確認してください。
- 再現に必要な操作や気づいた点は、分かる範囲で記録してください。

## 今後について

実際のテスト内容に合わせて、データ形式や連携手順、確認項目を少しずつ追加していく予定です。検証を通じて得られた知見を整理し、PC とモバイルデバイスを組み合わせた開発をよりスムーズに進めるための基盤にしていきます。
